燈號語義　🟢 資料在正常發布間隔內且通過三道關卡　·　🟡 資料過期、或未通過驗證而沿用前值　·　⚪ 未取得
方向箭頭　▲▼ 表示該指標本身相對上期的變動方向與幅度；對債市的多空由顏色與標籤另行標示（紅＝利多債市 綠＝利空債市，比照紅漲綠跌但以債券價格為準）。語義取決於當下情境的指標一律留白不編碼。
判讀文字　由量化規則自動生成（榮枯線、3個月年化、V/U比、百分位等）。需要跨指標推理的評論不自動生成，留白由人補。
CPI 雙軌　澳洲同時發布月度與季度 CPI，兩者並存且不可互相取代。RBA 貨幣政策聲明與 SMP 引用的是季度數字，月度只提供更即時的方向。各卡已標明「月度」或「季度」，比較時務必對齊同一口徑。
資料規則　一律取自官方 API 與官方發布：ABS Data API（SDMX）、RBA 統計表 CSV、AOFM Data Hub。私人機構指標（PMI、NAB、Westpac、Cotality、HIA）只取新聞稿已公開的頭條數字。未通過驗證即保留前值並亮黃燈，不顯示未經驗證的數字。
不含行情　本手冊為純總經參考，不收錄 BBSW、ACGB 殖利率、利差等日頻市場行情——行情以 TradingView 為準，手冊硬塞只會產生過期數字。
